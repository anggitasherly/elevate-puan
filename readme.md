# 🚀 Elevate Puan

**Elevate Puan** adalah sebuah proyek yang dirancang khusus untuk menjadi **pendamping UMKM** dalam membantu mengambil keputusan strategis di dalam bisnis mereka.

---

## 🛠️ Fitur Utama

* **Experiment** — Fitur untuk merancang, menguji, dan mensimulasikan berbagai strategi atau ide bisnis baru sebelum diterapkan secara penuh.
* **Finance Assessment** — Alat analisis untuk mengevaluasi kesehatan keuangan, melacak arus kas, dan memberikan penilaian kondisi finansial usaha.
* **Growth Insight** — Menyediakan analisis data mendalam dan rekomendasi berbasis data untuk mendorong pertumbuhan serta ekspansi bisnis UMKM.
